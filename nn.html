Neural networks

A neural network is a stack of very simple units, each one doing a little multiplication and addition. On their own they can only draw straight lines. Stacked in layers and trained together, they can learn almost any shape. Build one here and watch it learn.

02The limitWhy one is not enough

One neuron can only draw a straight line. Most real problems are not straight.

A pattern no straight line can split
Squashing functions

Here blue sits in two opposite corners and amber in the other two. Press Train one neuron: however long it trains, it gets stuck around half right, because no single straight line separates them.

Now press Train a small network: four neurons in a hidden layer feeding one output. Each hidden neuron draws its own line, and the output neuron combines them into a shape. It solves the pattern in seconds.

The bend matters

The squashing step is called the activation function. Without it, stacking neurons would just add straight lines into another straight line, however many layers you used. The bend is what lets layers build curves. Modern networks mostly use ReLU, which simply turns negatives into zero: cheap to compute and easy to train.

04BackpropagationPassing the blame backward

How does each weight know which way to move? The error is passed backward, layer by layer.

A tiny network, every number shown

This network has one input, one hidden neuron and one output, with two weights and two biases. Its job: when the input is 1, answer 1.

Press the button to walk through one training round:

Forward: the input flows through, and the network makes a guess. Loss: measure how wrong it is. Backward: starting at the output, work out how much each weight contributed to the error, using the chain rule from calculus. Each layer's share depends on the layer after it, so the blame flows backward. Update: nudge every weight against its gradient.

Why it matters

This is backpropagation. It computes the gradient for every weight in one backward sweep, whether the network has 4 weights or 400 billion. It is what makes training deep networks possible at all.

These are the neurons from the network you trained in step 3, layer by layer. The first layer can only split the map with straight edges. The next layer mixes those edges into corners and curves. The last layer assembles the final shape.

Real networks do the same thing at a vastly larger scale. In an image model, early layers detect edges, middle layers detect textures and parts, and late layers detect whole objects. In a language model, early layers handle spelling and grammar and later layers handle meaning.

Same parts, more of them

Every model in the table is built from the units on this page: weights, sums, activation functions, trained by backpropagation and gradient descent. The difference is the number of parameters, the amount of data and the computing power, which is what the AI infrastructure track is about.
