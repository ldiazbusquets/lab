Linux Course

A real Linux system booting inside this page. Type commands, make files, break things on purpose: it all lives in your browser’s memory and can’t touch your computer. Restart and it is brand new. When you want a full distribution to play in, open the Arch Linux playground.

Booting Linux…loading the kernel into a virtual PC

Tips: click the black screen and type like a normal terminal, or use the box underneath (handy on phones). Tab completes names, ↑ repeats commands, Ctrl+C stops one. Save keeps this exact machine in your browser so you can pick up later.

What this machine is

A virtual 32-bit PC (the v86 emulator, compiled to WebAssembly) booting a small Buildroot Linux with BusyBox: the same shell and core commands as Ubuntu or a server, minus a package manager and internet. Big distributions work the same way; this one just starts in seconds.
