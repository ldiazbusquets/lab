Workbench 05 · Agents, measured

Agent Sandbox

Module 13 explains how agents work. Here a small open model, running on your device, gets three tools (a calculator, a company directory and a currency converter) and eight tasks. You see every step it takes: the tool it calls, what comes back, and its answer, graded by code. One directory entry has an instruction planted in it, to see whether the agent obeys text it reads.

The tools

calc(expression). Arithmetic with + − × ÷, brackets, % and sqrt(). Parsed, never executed as code.

lookup(company). A small directory of four fictional companies: revenue, employees and headquarters.

convert(amount, currency). Dollars into euros, pounds or yen at fixed rates.

What is tested

Using tools (5). Tasks that need one or two lookups and a calculation.

Arithmetic (1). A calculation the model should hand to the calculator.

Honesty (1). The directory does not have the answer; the right reply is UNKNOWN.

Injection (1). A directory entry tells the AI to ignore its task. The right reply is the revenue, not what the planted text asks for.

How it runs

The model replies with one line: a tool call or a final answer. The page runs the tool and sends back the result, up to the step limit. Sampling is off, so the same model takes the same steps every time. Nothing is recorded; download the run if you want to keep it.

The agent loop

Think, Act, Read, Repeat

An agent is a model in a loop. It decides on an action, the program carries it out, and the result goes back into the conversation. The model never touches the tools directly: the page parses its line, checks it, and runs only the three tools it knows.

Why the planted instruction matters

Everything It Reads Is Input

An agent that reads web pages, emails or files reads text written by other people. If it treats that text as instructions, anyone who can put words in front of it can steer it. Defending against that is the main safety problem for agents.

Limits of this test

Eight Tasks, Small Models

Models this small often format a call wrongly or stop early; larger models do far better. Treat the scores as a demonstration of how agents are tested, not a ranking.

Live, not recorded. Qwen2.5 (Alibaba), Llama 3.2 (Meta) and SmolLM2 (Hugging Face) are open models, downloaded from Hugging Face and run with ONNX Runtime in your browser. The companies in the directory are fictional.
