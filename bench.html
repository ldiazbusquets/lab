Your device

Pages cannot see how much graphics memory is used, so memory is shown as the size of the weights, which is what has to fit.

The four questions

How it is timed

Load runs from the first request to a model ready to answer: download (if not cached), then compiling it for your hardware. First token is the wait before the first word appears, which is mostly reading the question. Speed is new tokens a second after that. Each setup answers one warm-up question first, so start-up costs are not counted twice.

Precision

Fewer Bits, Smaller and Faster

fp32 stores every weight in 32 bits, fp16 in 16, q4 in about 4. Cutting bits cuts the download and the memory the model needs by up to eight times, and usually speeds it up, because moving weights through memory is the slow part. The question is what it costs in answers: watch the Correct column.

Processor against graphics chip

Why GPUs Win, and When They Don’t

A graphics chip does thousands of multiplications at once, which is what a model mostly does. For a model this small the gap can be narrower than you expect, because there is less work to spread out and the GPU has its own start-up costs. Bigger models widen the gap.

First token against speed

Two Numbers, Two Experiences

The wait for the first word is what makes a chatbot feel slow; tokens a second is how fast it writes after that. Serving systems tune them separately: batching many users together helps speed but can lengthen the first-token wait.
