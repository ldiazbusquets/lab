Each sample document comes with ten questions: eight whose answer is in the text and two whose answer is not. A configuration scores a hit when a retrieved passage contains the answer, and a correct refusal when, for an unanswerable question, nothing clears the confidence threshold.

By default the answer is the single best-matching sentence, quoted with its passage number. Optionally, Qwen3 (0.6B, about 335 MB, needs WebGPU) writes the answer from the retrieved passages only.

Why chunk at all

Models Read Windows, Not Books

A language model can only take in so much text at once, and the more you give it, the more it gets distracted. Retrieval hands it the few passages that matter. Slide the chunk size and watch an answer get cut in half at small sizes, or buried in a long passage at large ones.

Keyword against meaning

Two Ways to Be Wrong

BM25 counts shared words, so it nails names and numbers but misses “profit” when the text says “net income”. Embeddings match meaning, but a passage can sound related without holding the answer. Hybrid ranks by both, which is what most production systems do.

Saying “I don’t know”

The Refusal Is a Feature

The two unanswerable questions in each test set are the most important ones. Set the confidence too low and the system answers everything, inventing support from the nearest passage. Too high and it refuses questions it could answer. The test table shows the trade-off.

How it runs. Search, chunking and the extractive answer are plain JavaScript on this page. The embedding model and Qwen3 download from Hugging Face and run on your device; your document never leaves it. The sample documents are original text written for this lab, and Northwind Bank is fictional.
